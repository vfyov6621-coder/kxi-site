Every hash above is computed by your own CPU. The server never mines — it only verifies proofs and credits the first hunter to land a valid nonce. Difficulty retargets are admin-signed.

/ console miner — cpu & gpu

# cpu — needs only python, nothing else curl -O https://kxi.kixprojects.online/kxi-miner.py python kxi-miner.py # gpu — brute force on your graphics card pip install pyopencl numpy python kxi-miner.py --gpu # mine into your browser wallet python kxi-miner.py --key <your 64-hex secret>

One file, opencl kernel inside. SHA-256 is computed by your hardware, the chain only verifies proofs. Run --benchmark to measure your hashrate, --info for chain state, --send 0.5 --to 0x… to transfer right from the terminal.
